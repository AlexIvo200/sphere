# Сфера — экзамен на эмпатию для допуска в политику

Прототип экзаменационной системы, которая не допускает до государственной власти
людей, лишённых эмпатии. Кандидат сдаёт письменный экзамен в формате **свободного
изложения** (не «да/нет»), а работу слепо проверяет **консилиум из 5 психологов
из разных стран**, отобранных системой случайно.

## Идея

Люди без эмпатии, приходя к власти, приносят хаос и боль. «Сфера» ставит на входе
в политику научно обоснованный барьер, построенный на учениях великих психологов:

| Психолог | Учение, положенное в основу вопроса |
|---|---|
| Карл Роджерс | Эмпатическое понимание: изложить позицию оппонента так, чтобы он сказал «да, именно это я имею в виду» |
| Дэниел Гоулман | Эмоциональный интеллект: распознавание и учёт чувств людей при тяжёлых решениях |
| Саймон Барон-Коэн | «Эрозия эмпатии»: зло как отношение к людям-объектам; коэффициент эмпатии (EQ) |
| Лоуренс Колберг | Стадии нравственного развития: дилемма Хайнца, универсальные ценности выше закона и выгоды |
| Мартин Хоффман | Эмпатический дистресс как двигатель реальной помощи |
| Стэнли Милгрэм | Подчинение авторитету: готовность отказаться причинять боль по приказу |
| Роберт Хаэр | PCL-R: подлинное раскаяние против маркеров психопатии |
| Альфред Адлер | Социальный интерес: власть как служение общности, а не компенсация |

## Защита от подкупа и предвзятости

1. **Случайный отбор консилиума.** 5 психологов отбираются криптографическим
   генератором случайных чисел (`crypto.randomInt`, перемешивание Фишера–Йетса) —
   состав нельзя предсказать и «купить заранее».
2. **Пять разных стран.** Все члены консилиума — из разных государств, и **ни один
   — из страны кандидата**.
3. **Слепая проверка.** Экзаменатор видит только номер работы и текст ответов —
   без имени, партии и страны кандидата.
4. **Изоляция экзаменаторов.** Оценки коллег скрыты до завершения всех пяти
   проверок — нет давления и конформизма.
5. **Право вето.** Любой из пяти при явных маркерах дефицита эмпатии накладывает
   вето с обязательным письменным обоснованием. Одно вето — отказ.
6. **Публичный реестр.** Общество видит все экзамены и вердикты (без текстов
   ответов и без имён экзаменаторов).

## Вердикт

Каждый экзаменатор ставит 0–10 по пяти критериям (когнитивная эмпатия,
аффективная эмпатия, сострадательное действие, нравственное рассуждение,
искренность) и пишет обязательное заключение (≥ 100 символов).

**Допуск** = средний балл ≥ 7,0 **и** не менее 4 из 5 одобрений **и** ноль вето.

## Запуск

Нужен только Node.js (≥ 18), без внешних зависимостей:

```bash
node server.js
# откройте http://localhost:3000
```

## Деплой на Vercel

Проект готов к Vercel из коробки: статика отдаётся из `public/`, все запросы
`/api/*` обрабатывает serverless-функция `api/index.js` (маршрутизация — в
`vercel.json`).

**Вариант 1 — через сайт (проще всего):**
1. Зайдите на [vercel.com/new](https://vercel.com/new) и войдите через GitHub.
2. Импортируйте репозиторий `AlexIvo200/sphere`, выберите ветку.
3. Ничего не настраивайте (Framework Preset: *Other*, без build-команды) и
   нажмите **Deploy**.

**Вариант 2 — через CLI:**
```bash
npm i -g vercel
vercel login
vercel --prod
```

⚠️ **Ограничение демо на Vercel:** файловая система serverless-функций
эфемерна — данные хранятся в `/tmp` и пропадают при пересоздании инстанса
(обычно через несколько минут простоя). Для постоянного хранения подключите
внешнюю БД (Vercel Postgres / KV, Supabase и т.п.) — вся работа с хранилищем
сосредоточена в `loadDb`/`saveDb` в `server.js`.

## Как попробовать (демо-сценарий)

1. Вкладка **«Кандидату»** — заполните данные и напишите 8 развёрнутых ответов
   (каждый ≥ 300 символов), отправьте.
2. Система покажет номер работы и — в демо-режиме — коды доступа пяти
   экзаменаторов (в боевой системе коды уходят психологам по защищённым каналам).
3. Вкладка **«Консилиуму»** — входите по каждому коду, читайте анонимную работу,
   ставьте оценки и пишите заключение (при необходимости — вето).
4. После пятой проверки система выносит вердикт; кандидат видит его на вкладке
   **«Мой результат»** вместе с обезличенными заключениями консилиума.
5. Вкладка **«Реестр»** — публичный список всех экзаменов.

## Устройство

```
server.js         — HTTP-сервер и API (Node stdlib, без зависимостей)
questions.js      — вопросы экзамена и критерии оценки
psychologists.js  — международный пул экзаменаторов (демо-данные)
public/           — веб-интерфейс (HTML/CSS/JS)
data/db.json      — хранилище (создаётся автоматически)
test.js           — сквозной тест: подача → 5 проверок → вердикт
```

## Ограничения прототипа

- Хранилище — JSON-файл; в продакшене нужна СУБД и аутентификация экзаменаторов.
- Пул психологов — демонстрационный; в реальности наполняется через национальные
  психологические ассоциации с верификацией лицензий.
- Демо-режим показывает коды доступа консилиума на экране подачи — только для
  того, чтобы весь цикл можно было пройти одному человеку.
