# 💼 Кредо — ежедневник инвестора

Простое мобильное приложение (PWA), где инвестор ведёт учёт своих должников и проектов:
кто сколько должен, по какому проекту, когда возвращать — и как об этом напомнить.

Всё работает **офлайн**, без сервера и регистрации. Данные хранятся только на устройстве
пользователя (`localStorage`), их можно выгрузить в резервную копию и перенести.

## Возможности

- **🎤 Голосовой ввод** — главный вход. Пользователь наговаривает одной фразой:
  «Иван должен сто тысяч рублей к 1 июня по проекту Кофейня, обязался запустить точку» —
  приложение само вытаскивает **имя, сумму, валюту, срок, проект и задачу**, показывает
  на подтверждение, и после проверки сохраняет должника (и при необходимости создаёт проект).
  Распознавание — через встроенный в браузер Web Speech API (бесплатно, без сервера),
  разбор фразы — собственный офлайн-парсер русского языка (`parser.js`).
  Понимает и проценты: «дал 100 тысяч **под 5% в месяц**».
- **🤖 AI-разбор (опционально)** — если в настройках указать свой API-ключ Anthropic,
  фразы разбирает Claude (`claude-opus-4-8`) со структурированным выводом — точнее на любых
  формулировках. Ключ хранится только на устройстве и уходит только на `api.anthropic.com`;
  при ошибке сети/ключа приложение тихо откатывается на локальный парсер.
- **📈 Проценты по долгу** — ставка за месяц или год, простой процент или сложный
  (капитализация). Начисление считается от даты займа, в карточке видно тело долга,
  набежавшие проценты и итог.
- **📇 Должники** — имя, контакт, сумма долга, привязка к проекту, срок возврата, заметки.
- **💰 Платежи** — частичный возврат, прогресс-бар, автоматическое закрытие долга.
- **💼 Проекты** — сколько вложено, ожидаемый возврат, ROI, статус.
- **🔔 Сроки и напоминания** — что горит и что просрочено. При включении — **фоновые
  уведомления** через Periodic Background Sync (Chrome/Android, установленная PWA):
  телефон сам напомнит о просрочках, даже если приложение закрыто. Где фоновая
  синхронизация не поддерживается — напоминания при открытии приложения.
- **📊 Дашборд с графиками** — сколько должны / просрочено / вложено, полоса «деньги в
  обороте» и донат-диаграмма распределения вложений по проектам (canvas, без зависимостей).
- **🕴️ Консьерж** — фишка приложения: 5 уровней тона напоминания
  (вежливо → дружески → официально → жёстко → «консьерж выехал»).
  Текст собирается автоматически, дальше — копировать или отправить в Telegram / WhatsApp.
- **⬇️ Бэкап** — выгрузка и загрузка данных в JSON.

## Путь пользователя

1. Открыл приложение → жмёт **🎤 Записать голосом**.
2. Наговаривает: *«Вложился в проект Кофейня, Иван должен сто тысяч к 20 июля,
   обязался запустить точку»*.
3. Приложение разобрало фразу и показало карточку **«Проверь, всё верно?»** —
   имя, сумма, срок, проект, задача. Пользователь правит при необходимости и сохраняет.
4. На **дашборде** видно, сколько всего должны, что горит, графики по портфелю.
5. Подошёл срок / просрочка → приходит **напоминание**.
6. Не платят → открывает должника, жмёт **🕴️ Вызвать консьержа**, выбирает тон,
   отправляет сообщение в мессенджер.
7. Заплатили → **💰 Платёж** (частичный или полностью) → долг закрывается,
   уходит из «горящих», сумма «мне должны» уменьшается. Всё, порядок.

## Запуск

Никакой сборки не нужно. Любой статичный сервер:

```bash
# вариант 1
npx serve .

# вариант 2
python3 -m http.server 8080
```

Открыть `http://localhost:8080` в браузере. На телефоне через «Добавить на главный экран»
приложение ставится как обычная иконка и работает офлайн.

## Технологии

Чистые HTML + CSS + JavaScript, без зависимостей. PWA (manifest + service worker).

## Структура

```
index.html     — разметка, онбординг, каркас
styles.css     — тёмная мобильная тема
parser.js      — офлайн-разбор голосовой фразы (суммы, даты, имена, проекты)
app.js         — состояние, экраны, формы, голос, графики, консьерж
manifest.json  — PWA-манифест
sw.js          — офлайн-кэш
```

> Голосовой ввод использует Web Speech API. Лучше всего работает в Chrome и на Android;
> в браузерах без поддержки поле распознавания заменяется ручным вводом текста —
> разбор фразы работает одинаково.

## Идеи для развития

- Облачное распознавание речи (Whisper) вместо браузерного.
- Web Push с сервером — гарантированные push на всех платформах.
- Импорт контакта должника из телефонной книги.
- Синхронизация между устройствами (опциональный бэкенд / облако).
- Больше «характеров» консьержа и локализация текстов.
